# سجل نقاط القطاعات الأمنية

تطبيق ويب بسيط (Node.js + Express + PostgreSQL) لإضافة وخصم نقاط القطاعات أسبوعياً.

## التشغيل محلياً
```
npm install
ADMIN_PASSWORD=كلمة_سر npm start
```
ثم افتح http://localhost:3000 — بدون DATABASE_URL يحفظ البيانات في مجلد data/ (للتجربة فقط).

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط قاعدة PostgreSQL. إذا موجود، التطبيق يستخدمها ويسوي الجداول تلقائياً. |
| `ADMIN_PASSWORD` | كلمة مرور الإضافة/الخصم/الحذف. إذا فارغة، أي أحد يگدر يعدّل. |
| `PGSSL` | اختياري: `false` لإطفاء SSL إذا قاعدة البيانات ما تدعمه. |

## الرفع على Render
الملف `render.yaml` يسوي خدمة الويب وقاعدة البيانات مرة وحدة (Blueprint).
